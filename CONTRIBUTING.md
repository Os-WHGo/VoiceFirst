# Contributing to VoiceFirst / Cómo colaborar

Thank you for your interest in accessible, free, voice-first language learning. We welcome scoped PRs, bug reports, corrections by native speakers, accessibility feedback and documentation.

## First steps
Read `README.md`, `AGENTS.md`, and `docs/STATUS.md`. Ask before making large architectural changes. Prefer one issue per bug/feature and one narrowly scoped PR per change. Tests: `npm run check`.

Suggested contributions: real iOS/Android Bluetooth audio tests; French Canadian pronunciation and culturally appropriate original prompts; native checks for Spanish, Brazilian Portuguese, German and Italian; voice interruption architecture; cognitive accessibility tests; privacy/security analysis.

## Privacy
Never post actual student audio, private logs, API keys, contact information or clinical labels in public issues. Use synthetic test fixtures.

## Legal status
An explicit OSS license is not yet selected. Before proposing changes that require redistribution or depending on external repositories, ask maintainers to resolve the license. Contributions need author permission appropriate for the future license.

Please be considerate of varying communication needs and languages, and include alternative text for visual artifacts.
